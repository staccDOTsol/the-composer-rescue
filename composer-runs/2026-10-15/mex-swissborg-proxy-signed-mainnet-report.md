## One signed mainnet-beta probe

I built a 497-byte, 11-key versioned packet using only live state: idempotent creation of the runtime wallet's BORG ATA followed by `withdraw` of one raw BORG unit from the proxy's BORG ATA. The packet used the current BORG mint, token program, proxy PDA, event authority PDA, current blockhash, and the runtime wallet's real signature. The sole `simulateTransaction` call used `sigVerify:true` and `replaceRecentBlockhash:false` on mainnet-beta. It reached `Withdraw` and rejected the `treasurer` account with **`NotTreasurer` 6002** before any transfer. The ATA setup was simulation-only and the failed packet rolled back. No transaction was submitted and no synthetic balance was used. Evidence and reproduction: [signed result](mex-outsider-withdraw-signed-mainnet.json), [probe script](mex-outsider-withdraw-signed-mainnet.js), [IDL lookup](mex-fetch-idl.js).

**Decision:** The selected MEX inventory has an independently quoted exit, but the tested outsider cannot withdraw it. The live trader role and observed swap signers also do not support an outsider-directed MEX route. Flash liquidity would not supply either privileged signature, so there is no supported immediate outsider or atomic flash-loan candidate for this selected proxy at the observed state. This is a gate conclusion for the selected proxy and tested instruction, not a whole-program proof or guarantee after role/state changes.
